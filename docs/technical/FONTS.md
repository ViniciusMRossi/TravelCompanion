# Fonts

Approved design:

- **Fraunces 600** — editorial display
- **Roboto** — operational UI

Font binaries are intentionally not distributed in this starter.

The scaffold temporarily uses `FontFamily.Serif` where Fraunces belongs and Android's normal sans-serif/Roboto family for operational UI.

Before visual-fidelity signoff, add Fraunces through an approved source and replace the fallback. Do not redesign typography because its binary is absent here.
