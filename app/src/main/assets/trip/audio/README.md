# Packaged audio

Real audioguide recordings go here, laid out by the paths declared in
`trip.json` (`cities/`, `attractions/`, `stories/`, `walks/`).

## Prototype placeholder — not trip content

`attractions/bascarsija.prototype.wav` is **not** an audioguide. It is a
synthetic placeholder so local playback, seeking and chapter changes can be
exercised on a real device before recordings exist.

- **Origin:** generated by `tools/make_prototype_audio.py` in this repository.
  720 s (the approved guide's length) of 8 kHz mono 8-bit PCM: a short sine
  marker at the start of each of the three chapters, silence in between. No
  third-party recording, no music, no speech.
- **Licence:** none required — authored here, treat as CC0 / public domain.
- **Why audible pitch changes:** one tone per chapter, so a chapter boundary
  and a seek can be *heard*, not just read off the UI. Twelve minutes of
  continuous tone would be unusable to test with, hence markers plus silence.
- **Size:** ~5.5 MB. Uncompressed WAV is the price of not shipping an encoder;
  the real recording will be far smaller.

### Replacing it

When the real Baščaršija audioguide exists:

1. drop the real file in and delete the placeholder;
2. in `trip-package/sample/sample-trip.json` (and the packaged copy) point
   `audio.bascarsija` at it with the correct `mimeType`;
3. keep `ag.bascarsija.durationSeconds` at the approved **720 s** and replace
   the placeholder chapter titles and offsets with the real ones;
4. re-run `python tools/validate_trip.py app/src/main/assets/trip/trip.json`.

The placeholder runs the full approved 720 s, so screen 05 reads
"Ouvir audioguia · 12 min" exactly as the approved prototype specifies, and the
duration on screen matches the file actually on the device.
