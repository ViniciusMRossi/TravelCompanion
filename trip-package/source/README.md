# Source Material

This directory contains inputs used by the content-generation workflow.

## itinerary/

Versionable itinerary source files.

## user-notes/

Optional non-sensitive notes/preferences.

## private/

Local sensitive/non-versioned source files such as tickets, vouchers, insurance and personal documents.

`private/` is ignored by Git.

Do not commit sensitive travel documents unless you deliberately choose a secure private-repository policy.
